# Pet Daily Health Care App
- Developed a full-stack pet health management application using React frontend and Python/Flask backend to track daily care activities, health metrics, and medical records.
- Designed relational database schemas using MySQL/SQLite to securely manage user profiles, pet information, and health records.
- Designed and integrated 3 RESTful microservices for account management, unit- conversion, and notifications, enabling independent functionality through HTTP-based communication to improve application modularity and maintainability.
